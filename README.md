# متجر عطور صقر الفاخرة | SAQR Luxury Egyptian Perfumes

مشروع متجر ولوحة تحكم متكامل لبراند العطور المصري الفاخر **«صقر»**، مبني بفلسفة تصميم شركة آبل (Apple Minimalist Luxury) المعززة بالأصالة المصرية، بدون بوكسات أو خطوط تقطيع، وبانسيابية تامة على الخلفية مباشرة.

---

## الميزات التقنية والتصميمية

1. **تصميم آبل الصارم (Apple Minimalist Luxury)**:
   - بطاقات منتجات انسيابية مباشرة على الخلفية المعتمة دون إطارات أو بوكسات.
   - تايبوجرافي عريض، فخم وموجز بطابع مصري أصيل.
   - سلايدر الأكثر مبيعاً ذاتي الدوران بانسيابية ناعمة وتوقف عند التفاعل.
   - هرم عطري تفصيلي هادئ (القمة • القلب • القاعدة).
   - تجربة Mobile-First 100%.

2. **سوبابيز كباك إند كامل (Supabase Backend & RLS)**:
   - **قاعدة بيانات حقيقية**: لا توجد بيانات وهمية عند الفشل أو عدم الاتصال؛ يتم إظهار لودر آبل الأنيق أو رسالة خطأ واضحة أو حالة الفراغ بدقة.
   - **إحصائيات الأكثر مبيعاً الحقيقية**: محتسبة ديناميكياً من واقع كميات عناصر الطلبات المؤكدة عبر View `view_bestsellers`.
   - **نظام العملاء التلقائي**: Trigger تلقائي يسجل بيانات كل مشترٍ وهاتفه وعدد طلباته ومجموع مدفوعاته في جدول `customers`.
   - **سياسات أمان صارمة (RLS)** لحماية الطلبات والعملاء.

3. **تجربة شراء سلسة بخطوة واحدة (Frictionless 1-Step Checkout)**:
   - كتابة الاسم ورقم الهاتف والمحافظة والعنوان مباشرة داخل دروار السلة.
   - الدفع عند الاستلام (COD) مع ميزة معاينة الزجاجة قبل الدفع.
   - كود تتبع مختصر فريد (مثل `SQR-4820`).
   - حفظ التوكن محلياً في متصفح وهاتف العميل للتعرف عليه ومتابعة طلبه فوراً.

4. **لوحة تحكم مؤمنة وشاملة (`/admin`)**:
   - إحصائيات المبيعات والأرباح الحقيقية والطلبات المعلقة.
   - إدارة الطلبات وتحديث حالاتها مباشرة (قيد المراجعة ➔ تم التأكيد ➔ جاري التجهيز ➔ خرج للتوصيل ➔ تم التسليم).
   - إضافة وتعديل وحذف العطور وتحديث المخزون.
   - عرض قاعدة بيانات العملاء وأرقامهم.
   - ضبط وتحديث مفاتيح Supabase من واجهة المستخدم مباشرة.

## خطوات التشغيل الفوري

### 1. تشغيل المتجر محلياً
```bash
npm run dev
```
سيعمل المتجر على: `http://localhost:3000`

### 2. تفعيل قاعدة البيانات في Supabase
1. افتح مشروعك في [Supabase](https://supabase.com).
2. ادخل على **SQL Editor**.
3. انسخ محتويات الملف `supabase_schema.sql` والصقها ثم اضغط **Run**.
4. ادخل على لوحة تحكم المتجر `/admin` (كلمة المرور الافتراضية: `saqr2026`) أو من تبويب **إعدادات Supabase**، ضع رابط مشروعك ومفتاح الـ Anon، وسيتم ربط كل شيء مباشرة!

## المسارات الأساسية
- `/` : المتجر الرئيسي الفاخر (الهيرو، السلايدر التلقائي، التشكيلة، السلة المدمجة).
- `/track` أو `/track/:orderCode` : صفحة المتابعة التفاعلية لمسار الطلب.
- `/admin` : لوحة التحكم وإدارة العطور والمبيعات.
